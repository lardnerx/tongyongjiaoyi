发展理念

平台经济与灵活就业，正成为劳动力市场的未来发展方向；互联网、大数据、AI 的技术成熟，为这一方向提供强有力的加持。

  • 对劳动者：从"打零工"升级为有信用、有保障、可持续的职业身份
  • 对服务交易：从"信息撮合"升级为全链路交易保障
  • 对平台：从"单一行业 App"升级为承载所有服务的通用引擎

市场机会

在线服务市场规模数万亿，但多数垂直服务仍停留在"信息撮合 + 线下交易"：

需求端
找靠谱服务者成本高，信息不透明、服务无保障。
供给端
服务者缺乏稳定获客渠道，好服务难沉淀为口碑。
平台端
垂直平台每入一行业就重搭系统，扩展慢、成本高。

不做单一行业 App，而是做一个承载所有服务交易的能力平台。

核心库不含任何行业逻辑，行业业务全部通过插件注入。

一个逻辑，无数行业

业务逻辑源于对网约车的抽象：需求（含位置）→ 匹配 → 上门服务 → 完成。

  • 网约车：A → B 出行，司机接驾送达
  • 陪驾：到 A 点陪驾，教练 1 对 1 陪练
  • 救援：到 A 点补胎 / 搭电 / 电车补电

凡符合最简逻辑的服务皆可纳入。行业是无限的，逻辑只有一个。

双向报价撮合 · 价格由市场说了算

  • 一改平台单方面定价、一家说了算的模式
  • 需求者按预算出价 · 服务者按价值报价
  • 大数据基于海量报价给出撮合报价，自动报价、公允定价

价格由市场双方共同议价 + 数据智能撮合形成。
