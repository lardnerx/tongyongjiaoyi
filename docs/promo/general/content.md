- **对平台**：从"单一行业 App"升级为承载所有服务交易的通用引擎。

## 二、平台定位

《即时百分百》是一个**通用在线服务交易平台**——底层是自研的通用双边市场交易引擎（UMCP），陪驾只是平台的第一个业务，而不是全部。

平台用七层协议栈（用户接入 → 需求抽象 → 智能匹配 → 交易支付 → 信任信用 → 数据智能 → 治理规则）抽象出所有服务交易的通用能力，任何行业业务都可以作为"插件"挂载进来。**一个平台，承载所有服务。**

### 一个逻辑，无数行业

平台的业务逻辑源于对网约车的抽象：**用户提出需求（含位置）→ 平台智能匹配 → 服务者到达位置提供服务 → 服务完成**。

- 网约车：用户提出 A → B 的出行需求，司机接驾送达；
- 陪驾：用户预约 A 点陪驾，教练到达进行 1 对 1 陪驾；
- 救援：用户车辆在 A 点抛锚，救援人员到达补胎 / 搭电 / 电车补电。

凡符合"需求（含位置）→ 匹配 → 上门服务 → 完成"这一最简逻辑的服务，都可以纳入平台。**行业是无限的，逻辑只有一个。**

## 四、六大核心卖点

### 卖点 1：插件化架构——业务即插即用

- 核心库不包含任何行业逻辑，行业业务全部以插件注入；
- 陪驾、网约车等行业插件已内置，按业务域自动路由；
- 新增一个行业 = 新增一个插件，交易、支付、信任、治理能力全部复用。

### 卖点 2：全链路交易保障

- 任务与交易**双状态机**强制校验，非法流转立即拦截；
- 从下单、派单、签到、服务、签退到评价，每一步状态清晰、可追溯；
- 支付担保 + 退款流程标准化，资金链路安全。

### 卖点 3：信任与信用体系

- 每个用户一份**跨业务信用档案**，服务评价沉淀为长期信用；
- 多维评分（如教学能力 / 耐心 / 安全记录）+ 技能徽章；
- 持证准入：声明式准入规则（如 `持教练证 && 信任分 ≥ 4.0`），从源头把关。

### 卖点 4：灵活支付——适配任何行业

- 6 种支付模式：一口价 / 动态计价 / 预付费 / 里程碑 / 计时 / 定金尾款；
- 已接入微信支付 V3，扫码支付 + 异步回调，安全可靠；
- 分佣规则可配置（陪驾默认 20%），结算透明。

### 卖点 5：双向报价撮合——价格由市场说了算

- 一改平台**单方面定价、一家说了算**的模式，需求者、服务者都可自主提出价格；
- 需求者按预算出价，服务者按价值报价，买卖双方共同议价；
- 平台基于**海量报价大数据**给出撮合报价，实现自动报价、公允定价。

### 卖点 6：生产级技术底座

- **安全**：JWT 认证、Redis 分布式限流、支付回调三重防重放、HTTPS 全链路；
- **稳定**：状态机 + 事件总线解耦，全量事件审计；
- **可扩展**：插件化 + 按域路由 + 跨域信任聚合，支持多行业并行增长。
