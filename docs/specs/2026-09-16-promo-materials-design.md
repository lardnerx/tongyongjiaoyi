# 《即时百分百》在线服务平台推介资料设计规格

**日期**：2026-09-16

## 一、背景与目标

平台为通用双边市场在线服务交易平台（项目代号 UMCP，Universal Market Coordination Protocol），
当前已上线第一个行业业务「陪驾」，后续将扩展更多在线服务（网约车、集采等）。
平台已具备生产级能力：七层协议栈、插件化多行业架构、跨域信任体系、6 种支付模式、
JWT 认证、限流、支付回调防重放、高德地图、WebSocket + 短信通知、PostgreSQL 持久化。

需要为该平台编制一套完整的推介资料体系，充分介绍平台优势，
覆盖四种读者场景：**投资人 / 服务商（供给方）/ 用户（需求方）/ 综合**，
并额外提供**单独的陪驾业务推介**。

## 二、平台名称与品牌

- 平台名称：《即时百分百》在线服务平台
- Slogan（主推）：一个平台，承载所有服务

### 四种形式的规格

| 形式 | 技术 | 规格 |
|------|------|------|
| 纯文字版 `content.md` | Markdown | 完整文案稿，可直接分发/粘贴 |
| PDF `promo.pdf` | fpdf2（项目已有中文方案，注册中文字体） | A4，每套 8-12 页 |
| 图文长页 `longpage.html` | 单文件 HTML，内嵌 CSS（无外部依赖） | 移动端适配，每套 10-12 屏 |
| 演示文稿 `slides.html` | 单文件 HTML，16:9 全屏翻页，键盘控制 | 每套 12-16 页 |

### 配图

- 每套生成 3-4 张差异化场景图（扁平插画风），共享素材放 `assets/`
- 页面图片统一使用 `https://trae-api-cn.mchost.guru/api/ide/v1/text_to_image?prompt=...` 生成链接（长页/演示稿内嵌）
- PDF 中配图使用本地生成图片（GenerateImage 产出到 `assets/`）

## 五、内容素材库（真实平台能力）

所有卖点均来自平台真实实现，禁止虚构：

| 能力 | 实现细节 |
|------|---------|
| 插件化架构 | 陪驾/网约车/集采 3 个插件已内置，按 domain 注册路由 |
| 七层协议栈 | L1 接入 → L2 抽象 → L3 匹配 → L4 交易 → L5 信任 → L6 智能 → L7 治理 |
| 任务/交易状态机 | TaskStatus / DealStatus 强制校验，非法流转 fail-fast |
| 匹配策略 | InstantMatch（实时派单）/ ScheduledMatch（预约推荐）/ Bidding（竞标）/ DirectPick（自选） |
| 信任体系 | WeightedSumTrustEngine 多维评分、SkillBadge 徽章、跨域 TrustAggregator 聚合 |
| 准入规则 | 声明式表达式（`hasCredential('coach_license') && trustScore >= 4.0`） |
| 支付 | 6 种支付模式（一口价/动态/预付费/里程碑/计时/定金尾款）、微信支付 V3、担保交易、退款 |
| 安全 | JWT 认证、Redis 分布式限流、支付回调防重放（时间戳+nonce+RSA）、HTTPS |
| 通知 | WebSocket 实时推送 + 短信（互亿无线） |
| 地理 | 高德地图：定位、逆地理编码 |
| 数据 | PostgreSQL 持久化、事件审计 |
| 部署 | Docker + Nginx + systemd/pm2，生产环境已运行 |
